## このZIPでは分からないこと

ZIPの中身は、manifest.jsonとアイコン2枚だけです。以下は含まれません。

- トピックYAML、PA定義、Listsの列や実レコード。
- 公開済みのトピックの具体的なバージョン・処理経路。
- Teams投稿時の受信・認証・実行ログやDLPの実際の拒否結果。
- 現在ユーザーのTeamsにインストールされているアプリの実パッケージ。

したがって、「配布元の設定に明白な不一致がない」ことと「失敗したTeams実行が正しい本体を通っている」ことは別です。パッケージの差し替えで直るとも判断できません。SSO関連項目が見当たらないことだけを原因にしません。
