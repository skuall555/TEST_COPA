# IsBlankの空引数エラーの修正

Studioで表示された `!IsBlank()` は引数がないためPower Fxのエラーになります。条件ノードの式を、次の式へ丸ごと置き換えて保存してください。

```powerfx
And(
    Topic.優先度表示検証 <> "合格",
    Topic.優先度様式再試行回数 < 1,
    Len(Topic.優先度表示原文) > 0
)
```

対象ノードは `conditionGroup_priorityFormatRetry` の `conditionGroup_priorityFormatRetry_item` です。優先度表示原文は、この条件より前でTrim済みの文字列として設定されているため、文字数が0より大きいかだけを確認します。

この条件は「形式が不合格」「まだ再試行していない」「正規化後の原文が空ではない」の3つが揃った場合に、1回だけ修復する条件です。空出力を再試行しない扱いは維持しています。

[3-9の全文](3-9-緊急保安業務エージェント_optimized.yaml)も同じ条件へ修正しました。今回の本体YAMLの変更は、この条件の1行だけです。条件だけをUIで直す場合、他の変数・ノード・接続設定を変える必要はありません。

回帰60件、Power Fx 194式、再試行の4ケース（空は実行しない、不合格で未試行なら実行する、1回実施済みなら再実行しない、合格なら実行しない）等は合格しています。Studioでの保存後の動作は未確認です。

今回提示された空引数はエラーの直接原因ですが、前回のYAMLには引数が入っていました。保存・編集・表示のどの段階で空になったかは特定していません。
