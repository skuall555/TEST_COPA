# 変更前後の機能対照表

「維持」は静的な構造・規則の維持を示し、実機の同一回答や回帰0の達成を示さない。

| 機能 | 改修後 | 確認根拠／未検証点 |
|---|---|---|
| 単一エージェント・3目的 | 維持 | 入口→専門のdialog、初回入力／履歴binding一致 |
| 廃止2-巡回エージェント | 復活なし | 新たなdialog無し |
| 内容確認 | 維持＋充足時だけ省略 | Index比較・回答・ガード・追加確認は残る |
| 条件から複数工法 | 維持 | 38件比較＋監査と独立3観点4ノードは無改変 |
| FG／KS／ねじ接合部別名 | 維持・現場FG表記整合 | 未定義略語を勝手に展開しない指示を追加 |
| 規定目的・引用 | 強化 | 最終ガードへ実本文も渡す。撮影PDF・外部Webを修理根拠にしない |
| 改訂文書候補・複数番号・0 | 維持 | 元Question、上限、候補タイトル表を保持 |
| 原文検索3本＋予備 | 維持 | 検索語へ履歴を含め、文書一覧の切詰めを撤廃 |
| アンカー・全文・続き・結合 | 条件改善 | 境界判定追加、続き無しはコピー、短さだけの原文棄却を廃止 |
| 変更前・変更後全文 | 指示強化 | 指定部分以外の逐語保持、候補ごとの独立原文照合。生成結果は実データ要確認 |
| 複数ROW・高／中／低・保留 | 維持＋全ROWの形式検査 | 形式検査は全文真正性の証明ではない |
| 独立監査03C・03D・03E | 維持 | 省略せず、原文取得条件・複数文理由を揃える |
| 改訂継続／終了 | 維持 | 継続時の検索語に追加指示が入る。Questionそのものは同一 |
| 案件保存 | 維持 | 全既存flowId・入出力のbinding一致 |
| 初動優先度・危険トリガー | 既存基準に今回指定の消防警察優先規則を追記 | 現在危険と改善により再評価。他の初動基準は保持 |
| 現場の問診／修理／番号／0 | 維持 | 無効番号だけ質問へ戻り検索の反復を省く |
| 画像事実→MS照合 | 維持＋安全保留 | AI Builderモデル／PDF指定を維持、要領未取得では措置済み無し |
| 画像の履歴累積・復帰 | 無改変 | Global履歴の追記式・EndDialogが完全一致 |
| 2・3枚目の写真 | 構造維持 | 別ターン添付の割り込み。実機で複数ターン確認必須 |
| 同一ターンの複数添付全件処理 | 今回追加なし | 元からFirst(Attachments)のみ。全件対応済みと主張しない |
| 明示「計測」 | 無改変 | SearchKnowledgeSourcesとSearchAndSummarizeContentの対比表示 |
| 通常回答の生JSON | 追加なし | 既存DEBUG履歴表示のみfalseで抑制 |

既存の初動ガイド固定文はそのまま保持した。元から固定であり、動的ガイド更新を実装したとは主張しない。現場機能を別設計へ拡張していない。危険トリガーと初動の安全性は必須実機回帰対象。

最新版では目的Questionを番号方式へ変更し、専門終了後は入口の継続Questionへ戻る。詳しくは08の追加改修仕様を参照。

画像v3では利用者指定によりMS-018を対象外とし、001〜017は再採番していない。外観の原文参照、機器別観察、実施済み採用チェックを追加した。詳細は09を参照。

3-9の優先度回答は実施状況・効果・対象を分離し、YAML側で高中低を表示する。要請高の強制適用とBooleanによる完了判定を追加。10を参照。

3-9の全保留問題に対し、内部出力指示を統一し、不適合時の修復を最大1回追加。修復失敗でも照合済みの措置・危険項目を残す。11を参照。

型エラーへの対応で、3-9の内部変数を型付きで初期化し、テーブルを段階ごとの別変数へ変更。外部の入出力名・接続は維持。12を参照。
