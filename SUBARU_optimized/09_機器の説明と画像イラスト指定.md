# 機器の説明と画像・イラスト指定

## ポケット警報器

床面・地面・棚・設備付近などに置く監視機器。筒状プローブを向ける手持ち検査機器として描かない。

```text
小型のポケット警報器が床面または設備付近に置かれ、周辺空気を監視している。作業員の手には持たれていない。機器の先端に細長いアンテナ状の筒や検査プローブはない。
```

## 可燃性ガス検知器

先端の筒・プローブ・吸引部等を対象へ向けて、作業員が手に持って検査する機器。

```text
作業員が、先端に細長い筒状のプローブが付いた可燃性ガス検知器を手に持ち、配管や設備の周辺を検査している。
```

YAMLには画像生成や画像URL付き画面カードのアクションがない。この指定文は画像分析の説明にも反映したが、画像自体は生成していない。別画面や生成サービスがある場合は、その設定へ適用する。
