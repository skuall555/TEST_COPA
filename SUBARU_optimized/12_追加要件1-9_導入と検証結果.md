# 追加要件1〜9の導入と検証結果

基準は前回の713b817（61e0c4aから作り直した版）。今回変更した導入用ファイルは、**3-9-緊急保安業務エージェント_optimized.yamlだけ**。

## 前回版を導入済みの場合

1. 現在の緊急保安トピックのYAMLを控える。
2. この版の[3-9のYAML全文](3-9-緊急保安業務エージェント_optimized.yaml)を開き、GitHubのRaw表示から全文コピーする。
3. Copilot Studioで既存の「3-9-緊急保安業務エージェント」のコードエディターを開き、全文置換して保存する。別トピックを新規作成しない。
4. トピックチェッカーを確認する。保存時にエラーが出た場合は公開せず、エラーのノードと内容を確認する。
5. 新しいテスト会話で、[追加103ケース](validation/additional_runtime_cases.csv)のうち境界値・実施済み更新・複数条件・保安柵の部分設置を優先して確認する。[前回48ケース](validation/restart_runtime_cases.csv)も回帰確認する。
6. 公開チャネルに適用する場合は、実機確認後に公開し、新しい会話で確認する。

**今回は入口・画像分析YAML、エージェント全体の「指示」、画像分析カスタムプロンプト、モデルの変更は不要。** これらは713b817と同一。AI BuilderのContextText／ImageInput、フロー・ナレッジの参照IDも変更していない。

## まだ前回版を導入していない場合

このブランチにある入口・3-9・画像分析の3つのYAMLと全体「指示」を一式で導入する。前回の[10の導入手順](10_61e0c4a基準_導入と検証結果.md)の導入部分を参照し、3-9には今回のファイルを使用する。08と10の検証内容は713b817時点の履歴で、今回の全文・差分・結果は11と12を参照する。

## 再生成・検証

リポジトリのルートで実行する。PythonとPyYAMLが必要。

```bash
python SUBARU_optimized/validation/rebuild.py
python SUBARU_optimized/validation/validate.py
python -m unittest discover -s SUBARU_optimized/validation -p 'test_*.py' -v
python SUBARU_optimized/validation/additional_report.py
```

.NET 8 SDKがある環境では次も実行できる。DLL・SDKはCopilot Studioの追加要件ではない。

```bash
python SUBARU_optimized/validation/native_restart/run.py --dotnet /tmp/subaru-dotnet/dotnet
```

rebuild.pyは不変の61e0c4aから前回の修正と今回の追加を順に適用する。今回の差分基準は713b817。報告書の再生成はadditional_report.py（restart_report.pyも同じ処理へ転送する）。
