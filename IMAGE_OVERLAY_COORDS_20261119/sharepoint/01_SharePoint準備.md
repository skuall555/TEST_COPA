# SharePoint準備（既存リスト利用版）

新しい座標用リストは作りません。既存の `AI_エージェント可視化` の案件行へ、最新画像1枚分のURL・寸法・座標を保存します。

Excelからのインポートも使用しません。既存リストへ列を追加する機能ではないためです。

途中で作成した `AI_ImageOverlay` や `AI_ImageOverlay_v2_20261119` が残っていても、この版では参照しません。いま削除する必要はありません。

## 1. 既存リストへ列を追加

`AI_エージェント可視化` を開き、右端の「列の追加」から次の12列を追加します。列名はPAとPower Appsで使用するため、半角英字のまま正確に作成してください。

|列名|Listsで選ぶ種類|必須|用途|
|---|---|---:|---|
|ImageToken|1行テキスト|いいえ|古い画像分析結果の誤上書き防止|
|ImageUrl|複数行テキスト（プレーンテキスト）|いいえ|Power Appsに表示する最新画像URL|
|ImageFileIdentifier|複数行テキスト（プレーンテキスト）|いいえ|一時画像ファイルの削除用|
|ImagePixelWidth|数値（小数点以下0桁）|いいえ|元画像の横ピクセル数|
|ImagePixelHeight|数値（小数点以下0桁）|いいえ|元画像の縦ピクセル数|
|ImageOverlayJson|複数行テキスト（プレーンテキスト）|いいえ|最大8個の目印・座標・タップ説明|
|ImageAnalysisNote|複数行テキスト（プレーンテキスト）|いいえ|画像分析結果の説明|
|ImageAnalysisStatus|1行テキスト|いいえ|`TEMP_SAVED`、`ANALYZED`等|
|ImageVersion|数値（小数点以下0桁）|いいえ|Power Appsの再読込判定|
|ImageUserText|複数行テキスト（プレーンテキスト）|いいえ|画像と同時に送られた質問・報告|
|ImageExpiresAt|日付と時刻|いいえ|一時画像の削除予定時刻|
|ImageErrorCode|1行テキスト|いいえ|保存・寸法・座標エラーの切り分け|

### 列作成時の注意

- すべて「必須」にしないでください。既存の案件保存処理が画像なしでも動くためです。
- `ImageAnalysisStatus` は選択肢ではなく、1行テキストで構いません。
- 既存の `ConversationId` と `CaseId` はそのまま使います。重複して作りません。
- `Title` は変更しません。
- ビューへ12列を表示する必要はありません。保存列として存在すれば動きます。

## 2. 画像ファイル用ライブラリ

一時画像そのものはリストの添付ファイルではなく、ドキュメントライブラリへ保存します。

1. `AI_エージェント可視化` と同じSharePointサイトの「サイトコンテンツ」を開きます。
2. 「新規」→「ドキュメント ライブラリ」を選びます。
3. 名前を `AI_TemporaryImages` にします。
4. PAの接続ユーザーへ編集権限、Power Apps利用者へ読み取り権限を付けます。

既に `AI_TemporaryImages` がある場合は、新しく作らずそのまま使用します。

## 3. 保存方式

- 1案件につき、`AI_エージェント可視化` の既存行は1行のままです。
- 画像を送るたび、その行の `Image...` 列だけを最新画像で更新します。
- 優先度、現場回答、案件IDなど既存列は画像PAから変更しません。
- 次の画像の保存成功後、前画像の一時ファイルを削除します。
- `ImageToken` が一致する場合だけ座標更新するため、遅れて返った古い分析結果を保存しません。

この方式は「1枚目で設置候補を表示し、2枚目で設置状況を再確認する」という最新画像中心の運用に適しています。画像履歴は保持しません。

## 4. インデックス

既存の `ConversationId` がインデックス化されていなければ、リスト設定→インデックス付きの列から追加します。「一意の値」はオフのままにします。

## 5. 完了確認

- `AI_エージェント可視化` に上記12列がある
- 既存案件の行・既存列が削除または変更されていない
- `AI_TemporaryImages` を開ける
- PA接続ユーザーが既存リストと画像ライブラリを編集できる
- Power Apps利用者が既存リストと画像を読み取れる

## 6. 重要な制限

4-9画像分析トピックは、現場アドバイザーが追加情報を待っている会話中の画像を処理します。この時点で案件行が存在することが前提です。

案件行が見つからない場合、PAは `CASE_ROW_NOT_FOUND` を返します。画像分析と利用者への回答は続行しますが、その画像と目印はPower Appsへ保存しません。画像PAが空の案件行を勝手に作ることはありません。
