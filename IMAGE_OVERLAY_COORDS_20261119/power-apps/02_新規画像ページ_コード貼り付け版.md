# Power Apps 新規画像ページ（既存結果画面を保持）

## 実現すること

- 既存の結果画面は変更しない
- 新規 `scrImageOverlay` で最新画像を表示
- 0〜1000の正規化座標で最大8個のマーカーを表示
- マーカーを押すとAIの説明をモーダル表示
- `Back()` で結果画面へ戻り、`varReply` と `varResultTab` を保持
- `ImagePixelWidth` / `ImagePixelHeight` が0でも表示

## 1. データソース更新

Power Apps Studioの「データ」で、既存の `AI_エージェント可視化` を更新する。

## 2. 画像ページを開くボタン

既存結果画面にボタンを1つ追加し、`OnSelect` に次を設定する。

```powerfx
Set(varImageConversationId, varAgentConversationId);
Set(varReturnResultTab, varResultTab);
Navigate(scrImageOverlay, ScreenTransition.None)
```

`FieldAdvisor_Submit.Run` と `FieldAdvisor_TextOnly.Run` で使用中の `varAgentConversationId` をそのまま使う。既存の送信式は変更しない。

## 3. 新規画面

Power Apps Studioで空の画面を1つ追加し、名前を `scrImageOverlay` にする。

`scrImageOverlay` のコード表示を開き、現在の子コントロールコードを、`scrImageOverlay_画面内貼り付け用.pa.yaml` の全文で置き換える。

このファイルは画面内へ貼る子コントロール専用で、`Control: Screen` を含まない。ラベル型も現在のSource Code schemaに合わせて `Control: Label` を使用する。

コード適用後、画面 `scrImageOverlay` 自体の `Fill` に次を設定する。

```powerfx
RGBA(245, 247, 250, 1)
```

画面の `OnVisible`:

```powerfx
Set(varMarkerPanelVisible, false);
Set(varSelectedMarker, Blank());
Select(btnLoadImageOverlay)
```

## 4. 画像とJSONの読込み

非表示ボタン `btnLoadImageOverlay` を追加する。

`Visible`:

```powerfx
false
```

`OnSelect`:

```powerfx
Refresh('AI_エージェント可視化');
Set(
    varImageRecord,
    LookUp(
        'AI_エージェント可視化',
        ConversationId = varImageConversationId
    )
);
Set(varLoadedImageVersion, Value(Coalesce(varImageRecord.ImageVersion, 0)));
Set(varOverlayLoadError, false);
Set(varOverlayReason, "");
Set(varOverlayShow, false);
Set(varMarkerPanelVisible, false);
Set(varSelectedMarker, Blank());
Clear(colImageMarkers);
If(
    !IsBlank(varImageRecord.ImageOverlayJson),
    IfError(
        With(
            {ParsedOverlay: ParseJSON(varImageRecord.ImageOverlayJson)},
            Set(varOverlayReason, Text(ParsedOverlay.reason));
            Set(varOverlayShow, Boolean(ParsedOverlay.show));
            ClearCollect(
                colImageMarkers,
                Filter(
                    FirstN(
                        ForAll(
                            Table(ParsedOverlay.markers) As JsonRow,
                            With(
                                {
                                    J: JsonRow.Value,
                                    NX1: Value(JsonRow.Value.x1),
                                    NY1: Value(JsonRow.Value.y1),
                                    NX2: Value(JsonRow.Value.x2),
                                    NY2: Value(JsonRow.Value.y2),
                                    NType: Text(JsonRow.Value.type),
                                    NColor: Text(JsonRow.Value.color)
                                },
                                {
                                    MarkerId: Text(J.id),
                                    MarkerType: NType,
                                    MarkerColor: NColor,
                                    Target: Text(J.target),
                                    MsId: Text(J.msId),
                                    Label: Text(J.label),
                                    X1: NX1,
                                    Y1: NY1,
                                    X2: NX2,
                                    Y2: NY2,
                                    Confidence: Text(J.confidence),
                                    Basis: Text(J.basis),
                                    Message: Text(J.message),
                                    IsValid:
                                        NX1 >= 0 && NX1 < NX2 && NX2 <= 1000 &&
                                        NY1 >= 0 && NY1 < NY2 && NY2 <= 1000 &&
                                        (
                                            (NType = "observed" && NColor = "green") ||
                                            (NType = "uncertain" && NColor = "yellow") ||
                                            (NType = "candidate" && NColor = "blue")
                                        )
                                }
                            )
                        ),
                        8
                    ),
                    IsValid
                )
            )
        ),
        Set(varOverlayLoadError, true);
        Set(varOverlayReason, "目印データを読み込めませんでした");
        Clear(colImageMarkers)
    )
);
Set(
    varImageRefreshActive,
    !IsBlank(varImageRecord.ImageToken) &&
    Coalesce(varImageRecord.ImageAnalysisStatus, "") <> "ANALYZED"
)
```

## 5. 元画像

画像コントロール `imgOverlayPhoto`:

```powerfx
Image         = If(
    IsBlank(varImageRecord.ImageUrl),
    Blank(),
    If(
        StartsWith(varImageRecord.ImageUrl, "https://tokyogasgroup.sharepoint.com/AI_TemporaryImages/"),
        Substitute(
            varImageRecord.ImageUrl,
            "https://tokyogasgroup.sharepoint.com/AI_TemporaryImages/",
            "https://tokyogasgroup.sharepoint.com/sites/NW_tool_library/AI_TemporaryImages/"
        ),
        varImageRecord.ImageUrl
    )
)
ImagePosition = ImagePosition.Stretch
X             = 16
Y             = 64
Width         = Parent.Width - 32
Height        = Parent.Height - 152
Visible       = !IsBlank(varImageRecord.ImageUrl)
```

`Stretch` は、元画像寸法が0でも正規化座標と画像の位置を必ず一致させるために使用する。新規画像ページだけに適用し、既存結果画面には影響しない。

## 6. マーカーボタン

`btnImageMarker1` を画像の前面に追加する。以下の `N` は1に置き換える。

```powerfx
Visible = CountRows(colImageMarkers) >= N && !IsBlank(varImageRecord.ImageUrl)

X = If(
    CountRows(colImageMarkers) < N,
    0,
    With(
        {M: Index(colImageMarkers, N)},
        imgOverlayPhoto.X + (M.X1 / 1000) * imgOverlayPhoto.Width
    )
)

Y = If(
    CountRows(colImageMarkers) < N,
    0,
    With(
        {M: Index(colImageMarkers, N)},
        imgOverlayPhoto.Y + (M.Y1 / 1000) * imgOverlayPhoto.Height
    )
)

Width = If(
    CountRows(colImageMarkers) < N,
    0,
    With(
        {M: Index(colImageMarkers, N)},
        Min(
            imgOverlayPhoto.Width - (M.X1 / 1000) * imgOverlayPhoto.Width,
            Max(32, ((M.X2 - M.X1) / 1000) * imgOverlayPhoto.Width)
        )
    )
)

Height = If(
    CountRows(colImageMarkers) < N,
    0,
    With(
        {M: Index(colImageMarkers, N)},
        Min(
            imgOverlayPhoto.Height - (M.Y1 / 1000) * imgOverlayPhoto.Height,
            Max(32, ((M.Y2 - M.Y1) / 1000) * imgOverlayPhoto.Height)
        )
    )
)

Fill = Switch(
    Index(colImageMarkers, N).MarkerType,
    "observed",  RGBA(38, 166, 91, 0.22),
    "uncertain", RGBA(255, 193, 7, 0.26),
    "candidate", RGBA(24, 111, 194, 0.22),
    RGBA(0, 0, 0, 0)
)

BorderColor = Switch(
    Index(colImageMarkers, N).MarkerType,
    "observed",  RGBA(24, 111, 67, 1),
    "uncertain", RGBA(180, 110, 0, 1),
    "candidate", RGBA(22, 100, 154, 1),
    RGBA(80, 80, 80, 1)
)

BorderThickness = 3
Text = Text(N)
Tooltip = Index(colImageMarkers, N).Label & Char(10) & Index(colImageMarkers, N).Basis
OnSelect = Set(varSelectedMarker, Index(colImageMarkers, N)); Set(varMarkerPanelVisible, true)
```

`btnImageMarker1` を7回複製し、名前と `N` を2〜8へ変更する。

## 7. マーカー説明パネル

画面の最前面へ背景、パネル、ラベル、閉じるボタンを置く。すべての `Visible`:

```powerfx
varMarkerPanelVisible && !IsBlank(varSelectedMarker)
```

タイトル:

```powerfx
varSelectedMarker.Label
```

種類:

```powerfx
Switch(
    varSelectedMarker.MarkerType,
    "observed", "画像で確認した対象",
    "uncertain", "追加確認が必要な対象",
    "candidate", "設置・操作の候補",
    ""
) & If(IsBlank(varSelectedMarker.MsId), "", "　" & varSelectedMarker.MsId)
```

本文:

```powerfx
varSelectedMarker.Message
```

AIの根拠:

```powerfx
"AIが画像で見た根拠：" & varSelectedMarker.Basis
```

閉じるボタン `OnSelect`:

```powerfx
Set(varMarkerPanelVisible, false);
Set(varSelectedMarker, Blank())
```

## 8. 画像分析の自動更新

タイマー `tmrImageOverlayRefresh`:

```powerfx
Duration  = 5000
AutoStart = true
AutoPause = true
Repeat    = varImageRefreshActive
Visible   = false
OnTimerEnd = If(varImageRefreshActive, Select(btnLoadImageOverlay))
```

## 9. 結果画面へ戻る

戻るボタンの `OnSelect`:

```powerfx
Set(varMarkerPanelVisible, false);
Set(varSelectedMarker, Blank());
Set(varResultTab, varReturnResultTab);
Back(ScreenTransition.None)
```

`Navigate(ホーム画面)` は使わない。`varReply` も初期化しない。これにより、画像ページから戻った後も、以前の結果と選択中のタブが残る。

## 10. 表示案内

画像下のラベル:

```powerfx
If(
    IsBlank(varImageRecord),
    "現在の会話に保存された画像はありません。",
    varOverlayLoadError,
    "AIの目印データを読み込めなかったため、画像だけを表示しています。",
    Coalesce(varImageRecord.ImageAnalysisStatus, "") <> "ANALYZED",
    "画像を分析中です。完了後に目印を自動更新します。",
    CountRows(colImageMarkers) = 0,
    If(IsBlank(varOverlayReason), "表示対象の目印はありません。", "目印なし：" & varOverlayReason),
    "色枠をタップすると、AIの確認根拠と残る対応を表示します。"
)
```
