## Teamsでの確認

Teamsでテスト用の現場報告を送ると、次の順になります。

```text
📍 現場アドバイス

【② 初動措置の優先度】
🔴 高
…
🟠 中
…
🟢 低
…

【③ 確認したいこと】
…

【④ ネクストアクション】
…
```

同じ会話・同じ案件で次の報告を送ると、先頭に **「① 前回報告からの変更点」** が付きます。初回は①を表示しません。P05などの内部番号は、Teams表示では措置名へ置き換えます。

比較は**この版を適用してから、同じ会話内に保持された直前の現場判定**が対象です。新しい会話・セッション再開後に、SharePointの過去判定を自動読込みする機能は今回追加していません。会話・案件・利用者・チャネルが違う情報を比較に使わず、判定項目が消えたことを解消とは扱いません。

コパスタ内のテスト画面やTeams以外のチャネルでは、従来形式のまま表示されます。最終確認は公開したエージェントをTeamsから行ってください。チャネルが `msteams` と渡ることも実機で確認します。
