# Power Apps側の変更仕様

今回のトピックコードだけでもCopilot Studioの回答とListsへの本文保存は動きます。ただし、Appsに専用欄を表示するにはApps側で次の対応が必要です。

## 追加する表示欄

回答本文の先頭にある、次の範囲を表示します。

- 開始：`【ユーザーへの回答】`
- 終了：`【確認できた事実】`

質問のない進捗報告では値は `ー` です。

回答本文を `statusText` とした場合の抽出例です。

```powerfx
With(
    { statusText: Coalesce(ThisItem.LatestStatus, ThisItem.InitialStatus, "") },
    If(
        "【ユーザーへの回答】" in statusText,
        Trim(
            First(
                Split(
                    Last(Split(statusText, "【ユーザーへの回答】")).Value,
                    "【確認できた事実】"
                )
            ).Value
        ),
        "ー"
    )
)
```

Appsの既存式で分割結果の列名が `Result` になっている場合は、上の `.Value` を `.Result` に読み替えてください。実際のデータカード名や変数名は現在のAppsに合わせます。

## 既存表示を壊さない条件

- `【確認できた事実】` 以下の従来の見出し名と順序は維持しています。
- Listsの列追加は不要です。
- PAの `text_2` には、従来どおり回答本文全体を渡します。
- 新しい状態 `対応済み【!】` を完全な `対応済み` と同じ色・完了扱いにしないでください。警告色または要確認表示にします。

## Appsテストで確認すること

1. `【ユーザーへの回答】` が専用欄へ表示される。
2. `【確認できた事実】` 以下の従来表示が欠けない。
3. `ー` の場合に空欄へするか、そのまま表示するかを決める。
4. `対応済み【!】` が完全完了として集計されない。
