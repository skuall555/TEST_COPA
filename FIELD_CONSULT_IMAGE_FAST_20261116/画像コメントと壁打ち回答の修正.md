# 画像コメントと壁打ち回答の修正

## 問題1：画像コメントがLists保存本文では「ー」になる

画像分析トピックは無関係画像へのコメントを作っていましたが、3-9が再判定を開始すると回答欄を `ー` に初期化していました。そのため、画像画面ではコメントが見えても、PAへ渡す3-9の回答とLists保存本文では `ー` になっていました。

### 修正

1. 4-9が作成した `Global.写真ユーザー回答テキスト` を3-9が確認
2. コメントが `ー` 以外なら、3-9の `【ユーザーへの回答】` へ引継ぎ
3. 従来の優先度本文と一緒に既存PAへ送信
4. Lists保存成功後、一時コメントを `ー` へ戻す

無関係画像は現場事実履歴へ追加しないため、画像コメントを保存しても優先度は変えません。

## 問題2：相談回答が検索0件の報告になる

相談時にライブのナレッジ検索結果をそのまま回答欄へ使っていたため、検索0件では `Answer not Found in Search Results` と「原文を取得できなかった」という文が表示されました。これは壁打ち回答になっていませんでした。

### 修正

相談経路からライブ検索を外しました。代わりに、次を別の生成AIへ渡します。

- マニュアルから固定した緊急保安早見表
- 初報
- 累積した現場報告
- 現在表示中の優先度判断
- 今回の相談文

相談AIは、既に言えることを最初に回答し、条件で対応が変わる場合だけ確認を最大2点返します。検索結果や原文取得の有無には言及しません。

優先度AIとは分離しているため、相談回答が空でも優先度判定・PA・Listsは止まりません。

## 質問と進捗が混ざる場合

`不在らしいが、警報器が鳴っている。どうしよう？`のような入力は、次の2つへ同時に使います。

- 壁打ち回答：どう考え、何を確認し、どの条件なら対応が変わるかを回答
- 優先度再判定：不在と警報器鳴動を現場事実として反映

質問部分やAI回答そのものは現場事実にしません。

## 再貼り付け

v2を導入済みの場合、`3-9_貼り替え用.txt`だけを再貼り付けます。4-9、PA、Listsの変更は不要です。
