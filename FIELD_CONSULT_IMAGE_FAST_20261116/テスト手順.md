# テスト手順

Copilot Studioのテスト画面で、新しい会話から順に試してください。

## テキスト

1. `台所でガス臭い`
   - `【ユーザーへの回答】` は `ー`
   - 従来の優先度表示も続けて出る
   - 初回だけ案件保存PAが動く
2. `消火器設置済み`
   - `【ユーザーへの回答】` は `ー`
   - 消火器の状態が従来どおり更新される
3. `このあと、どんな調査をすればいいんだっけ？`
   - `【ユーザーへの回答】` に、取得したマニュアルを根拠にした回答が出る
   - `【確認できた事実】` 以下も同時に出る
   - 質問文だけを理由に優先度や対応済み状態が変わらない
4. 現場対応と無関係な質問
   - 対象外である旨が回答欄に出る
   - 現場アドバイザーは停止せず、従来の優先度表示も出る
5. `不在らしいが、警報器が鳴っている。どうしよう？`
   - `Answer not Found in Search Results`を出さない
   - 原文・検索結果を取得できなかったという回答を出さない
   - マニュアル早見表と既報に基づき、まず取るべき考え方と確認事項を直接回答
   - 不在と警報器鳴動を現場事実にも反映

## 画像

1. 鉢植えなど、明確に無関係な画像
   - 画像が何に見えるかを `【ユーザーへの回答】` に表示
   - 活動マップで `02A_撮影要領の取得` と `02B_撮影要領との照合判定` が呼ばれない
   - 現場の優先度が変わらない
   - 続けて「反映」と送ると、3-9とLists保存本文の `【ユーザーへの回答】` に画像コメントが入り、`ー`にならない
2. 関連する対象物が鮮明で、設置場所も分かる画像
   - 従来どおり撮影要領と照合される
3. ポケット警報器本体と設置は確認できるが、周囲が写らず場所の適合が分からない画像
   - `対応済み【!】`
   - 再撮影依頼が `【確認したいこと】` に出る
   - 高優先度の完全完了にはならない
4. ボケており、ポケット警報器かどうか自体を断定できない画像
   - 対応済みにはせず `要確認`
5. 対象物はないが、炎・煙・危険な着火が写る画像
   - 無関係画像として終了しない
   - 危険事実が追加情報と確認事項に出る
6. 関連画像を5分以内に続けて2枚送る
   - 2枚目は、活動マップで `02A_撮影要領の取得` を省略
   - 第1段画像分析と第2段照合判定は毎回実行される

## 公開前の合格条件

- 保存エラーがない
- 上の全ケースで回答が停止しない
- PAの既存案件保存・更新が従来どおり動く
- Listsの既存列へ本文が保存される
- Apps変更後、回答欄と従来の優先度欄を両方表示できる
