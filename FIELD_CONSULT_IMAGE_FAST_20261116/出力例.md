# 出力例

実際の優先度・根拠・回答は、報告事実と取得したマニュアル原文により変わります。以下は形式の例です。

## 進捗報告だけの場合

```text
【ユーザーへの回答】
ー

【確認できた事実】
└消火器を設置済みとの報告がある

【初動措置　優先度：高】
（従来の表示）
```

## 途中で相談した場合

```text
【ユーザーへの回答】
└取得したマニュアル原文では、現在の状況では〇〇を確認する手順が示されています。まず〇〇を確認してください。

【確認できた事実】
（既報の事実）

【初動措置　優先度：高】
（従来の表示）
```

質問文と回答文そのものは、実施済み・未実施の現場事実として使いません。

## 設置は確認できるが、場所の適合を確認できない画像

```text
【ユーザーへの回答】
ポケット警報器の設置は確認できましたが、設置場所の周辺が写っていないため、場所の適合を確認できません。周辺を含めて再撮影してください。

【初動措置　優先度：高】
└ポケット警報器等の設置：対応済み【!】　根拠：ポケット警報器の設置は写真で確認できるが、設置場所の周辺範囲は未確認
```

## 明確に無関係な画像

```text
【ユーザーへの回答】
送っていただいた画像は鉢植えの画像に見えており、進捗報告に該当する要素は見当たりませんでした。ポケット警報器などをAIが見落としている場合は、コメントで教えてください。
```

この場合、撮影要領の検索と第2段判定を行わず、現場履歴と優先度も変更しません。
