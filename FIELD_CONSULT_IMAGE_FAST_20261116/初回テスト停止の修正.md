# 初回テスト停止の修正

## 発生した現象

`台所でガス臭い`という初報で、優先度回答が空または形式不合格となり、未検証回答の送信停止へ進みました。

## 原因

初版では、相談用の `ANSWER` ブロックを、既存の厳格な優先度AIの内部出力へ追加していました。そのため、質問のない初報でもAIが `[[ANSWER]]` を含む新形式を完全に返さないと、優先度回答全体が不合格になりました。

## 修正

- 優先度AIを、変更前と同じ `[[FACTS]]` 開始形式へ戻しました。
- `【ユーザーへの回答】` は優先度AIと別経路で作ります。
- 進捗報告と初報では、回答欄をAI生成せず `ー` にします。
- 質問のときだけマニュアル検索を行います。
- 検索0件または相談回答が空でも、優先度判定・PA・Listsは続行します。
- 質問文を現場事実の履歴へ追加しません。

## 再貼り付けが必要なファイル

`3-9_貼り替え用.txt`だけを、修正版へ再貼り付けしてください。

`4-9_貼り替え用.txt`は今回の停止原因ではなく、変更していません。

## 再テスト

新しい会話で `台所でガス臭い` と入力します。

期待結果：

1. `【ユーザーへの回答】` は `ー`
2. `【確認できた事実】` 以下の従来回答が表示される
3. 優先度回答の生成結果が空という停止メッセージが出ない
4. 既存PAが実行され、Listsへ新しい行が作成される
