# フロー定義の扱い

実際のPower Automateフロー本体・接続参照・列定義は未提供です。存在しない本番フローや接続先を埋めた「インポート用JSON」は含めていません。

`../tools/flow_definition.py` が実値確認後にworkflow定義を生成します。`../tools/patch_export.py` は、実環境からエクスポートした同じエージェント用フローへ定義を適用したコピーを作ります。詳細は `../docs/導入手順.md` と `../docs/保存フロー契約.md`。

生成版の処理はテストで実際に生成したworkflowを使って検証していますが、SharePointコネクターとフロー実行基盤は模擬です。接続・インポート・実行は環境側で確認する必要があります。
